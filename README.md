# India Village Weather 🌦️

A lightweight Android application built in **100% Kotlin** that provides hyper-local, village-level weather forecasts and agricultural weather insights across India.

---

## ✨ Features

### 📍 Village-Level Location & Search
- **Pan-India Village Coverage:** Search and select weather data down to the village, taluka/tehsil, district, and state levels across India.
- **GPS Auto-Detection:** Automatically detect the user's current village/locality using device location services.
- **Saved Locations / Favorites:** Bookmark multiple villages or towns for quick switching and daily monitoring.

### 🌡️ Real-Time Weather & Forecasts
- **Current Weather Conditions:** Live temperature, "feels like" temperature, humidity, wind speed & direction, atmospheric pressure, and visibility.
- **Hourly Forecast:** Detailed hour-by-hour temperature, precipitation probability, and sky condition breakdown.
- **Multi-Day / 7-Day Forecast:** Extended daily high/low temperatures, rainfall expectations, and weather summaries.
- **Sunrise, Sunset & UV Index:** Daily solar timings and UV exposure levels.

### 🌾 Rural & Agricultural Insights
- **Rainfall & Precipitation Tracking:** Expected rainfall volume (mm) and rain probability tailored for farming and local planning.
- **Severe Weather Alerts:** Warnings for heavy rain, thunderstorms, heatwaves, cold waves, and gusty winds.
- **Offline Caching:** View the last fetched weather forecast even in low-connectivity or offline rural areas.

### 🎨 User Experience & Performance
- **Clean, Responsive UI:** Built with modern Android UI components for fast loading on all screen sizes.
- **Pull-to-Refresh:** Instant manual refresh for up-to-date weather data.
- **Lightweight & Battery-Friendly:** Optimized network calls and background caching for low data usage.
